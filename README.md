# Bipalo · versiones

Instaladores de **Bipalo**, el programa de caja (TPV) e inventario para comercios.

Este repositorio solo guarda las versiones publicadas. El código no está aquí.

## Descargar

Las versiones están en **[Releases](../../releases)**:

| Sistema | Archivo |
|---|---|
| Windows | `Bipalo-X.Y.Z-windows-x64.exe` |
| macOS | `Bipalo-X.Y.Z-mac-universal.dmg` |
| Linux | `Bipalo-X.Y.Z-linux-x86_64.AppImage` o `Bipalo-X.Y.Z-linux-amd64.deb` |

## Actualizaciones

Bipalo busca versiones nuevas en este repositorio al abrirse y cada pocas horas. Las descarga en
segundo plano y las instala al cerrarse el programa, siempre después de hacer una copia de
seguridad.

Para comprobar si hay versión nueva, el programa solo descarga los archivos públicos de esta
página (`latest*.yml` y el instalador). No envía ningún dato del comercio.
